Я создала данный бот используя Pixabay для поиска и скачивания нужных изображений. С помощью команды /find вы задаёте запрос, а бот подыскивает вам три картинки, одну из которых вы можете скачать.
Я не расчитываю, что этот мини-проект кто-то увидит, поэтому не пишу условия пользования, и тому подобные вещи.
